# Simulation Evidence

This directory contains screenshots documenting a controlled ransomware simulation in a virtual lab.

## Evidence Categories

- Initial state of test files
- C2 monitoring dashboard
- Simulated ransom-note interface
- Invalid-key validation
- Attacker-side status messages
- File-state verification

All evidence should use synthetic test data. Sensitive information, credentials, and personal files must not be included.

Screenshots document observed behavior only; they do not independently prove encryption, decryption, or successful recovery.
